# Lunas 3D

Loja online da Lunas 3D — impressão 3D em Fortaleza-CE.

Next.js 16 · TypeScript · Tailwind CSS v4 · shadcn/ui · Supabase

```powershell
npm install
Copy-Item .env.example .env.local   # e preencha
npm run dev                         # http://localhost:3000
```
