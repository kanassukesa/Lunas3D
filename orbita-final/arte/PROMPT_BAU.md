# Baú de recompensas: 3 imagens (uma por mensagem, no MESMO chat)

O ChatGPT não faz animação. Por isso você pede **3 quadros do mesmo baú**, e o jogo anima trocando entre eles:
o baú respira, chacoalha no quadro "entreaberto", abre com um clarão no quadro "aberto", sai o feixe de luz e os prêmios saltam.

**Importante:** faça as 3 no **mesmo chat**, uma depois da outra. Assim ele mantém o mesmo baú, o mesmo ângulo e o mesmo tamanho.

---

## Mensagem 0 (configuração, mande uma vez)

```
Vou te pedir 3 imagens do MESMO baú de tesouro para o meu jogo mobile "Órbita Final", uma por mensagem.
Elas vão ser quadros de uma animação, então as 3 precisam ter EXATAMENTE o mesmo baú, a mesma câmera,
o mesmo ângulo, o mesmo tamanho e a mesma posição no quadro. Só muda a tampa (fechada, entreaberta, aberta).

Estilo fixo para as 3:
- Baú de tesouro sci-fi futurista, arte 3D pintada semi-realista de jogo mobile premium, polido, brilhante.
- Corpo de metal azul-escuro escovado com placas hexagonais, cantoneiras e faixas DOURADAS reforçadas,
  frisos de luz neon CIANO nas bordas, uma fechadura dourada no centro da frente com uma gema hexagonal brilhante.
- Vista frontal levemente de cima (3/4 de cima, uns 20 graus), baú centralizado e inteiro, ocupando ~70% da largura.
- Formato QUADRADO 1:1.
- Fundo PRETO puro (#000000), liso, sem chão, sem estrelas, sem gradiente, sem sombra no chão.
- Sem texto, sem letras, sem números, sem logotipo, sem moldura, sem interface. Arte original.
Gere UMA imagem por pedido, nunca junte as três numa imagem só.
Responda "ok" e espere.
```

## Mensagem 1: fechado

```
Imagem 1 de 3 (quadrado 1:1): o baú FECHADO, tampa totalmente encaixada, a gema da fechadura acesa em ciano,
um brilho suave saindo pelos frisos. Fundo preto puro. Nome do arquivo: bau_fechado.png
```

## Mensagem 2: entreaberto

```
Imagem 2 de 3 (quadrado 1:1): o MESMO baú, mesma posição e tamanho, agora com a tampa levantada só um pouquinho
(uns 10 graus), e uma luz branca-azulada muito forte vazando pela fresta, raios de luz escapando pelos lados,
pequenas faíscas. Fundo preto puro. Nome do arquivo: bau_entreaberto.png
```

## Mensagem 3: aberto

```
Imagem 3 de 3 (quadrado 1:1): o MESMO baú, mesma posição e tamanho, agora TOTALMENTE ABERTO com a tampa
inclinada para trás (uns 110 graus). Dentro, um monte de moedas douradas e cristais azuis e roxos brilhando,
e um clarão de luz branca-dourada saindo de dentro para cima. Fundo preto puro. Nome do arquivo: bau_aberto.png
```

---

**Dica:** se a 2 ou a 3 sair com o baú diferente (outra cor, outro ângulo), responda:
"Refaça mantendo exatamente o mesmo baú da imagem 1, mesma posição e tamanho, só mudando a tampa."

Quando tiver as 3, me manda (soltas ou num ZIP). O jogo já está pronto para elas: assim que eu colocar, o baú desenhado de agora é trocado pelo de vocês, com a mesma animação.
